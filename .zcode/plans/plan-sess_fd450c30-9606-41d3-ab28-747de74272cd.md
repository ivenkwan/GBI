Phase 16 — Reports & dashboards: the capstone. Real multi-chart reports from natural language, persisted and browsable. LLM-planned + deterministic execution (2 LLM calls per report).

## 1. Persistence (migration 0005_reports + init.sql mirror + ORM)
- `reports` table: id, tenant_id FK, user_id, prompt, title, summary (TEXT), status, created_at — RLS FORCE + tenant_isolation + genbi_app grants + indexes (tenant, created_at), exactly the 0004 recipe.
- `report_sections` table: id, report_id FK, tenant_id, position, metric_name, section_title, chart_spec JSONB, chart_svg TEXT (SVG not base64-PNG — lighter, renders via ChartCard), data_total, row_count, narrative, created_at — same RLS/grants.
- ORM models Report/ReportSection in db/models.py; literal-SQL statements throughout.

## 2. Report service (`app/services/reports.py` + generation pipeline)
- Persistence: copy the conversations.py pattern verbatim (_dsn/_connect + GUC; writes fail-open, reads raise; per-user predicates beyond RLS).
- `generate_report(prompt, tenant_id, user_id, max_sections=3)`:
  1. **Plan** (LLM call 1): catalog via `get_cube_client().get_agent_context(query=prompt)` → one invoke (fast model, temp 0, response_format json, new prompt `.claude/prompts/report-planner-system.md`) returning `{"title", "sections": [{"metric", "title", "dimension"?, "granularity"?}]}` (2–max_sections). Fail → 503-style error; malformed JSON → single-section fallback on a default metric.
  2. **Execute per section** (deterministic, fail-open per section): `cube.query([metric], [dimension]?, time_dimensions?, tenant_id=tenant)` → rows; build ChartAssemblyInput (Line+month for time granularity, Bar otherwise); `FlintChartBridge(tenant_id).render(spec, output_format="svg")` → svg; collect data_total/row_count.
  3. **Summarize** (LLM call 2): one invoke (fast model) over all section summaries → overall narrative.
  4. Persist report + sections (best-effort — response carries the full report even if persistence fails; warning added).
- `list_reports(user_id, tenant_id)` and `get_report(report_id, tenant_id)` reads.

## 3. API (reports.py rewrite; router already registered)
- `POST /reports/generate` — {prompt: str 1–2000, max_sections: 2–4 = 3} → full report incl. sections (each: title, metric, chart_spec, chart_svg, narrative, total) + report_id. 503 REPORT_GENERATION_FAILED when planning fails.
- `GET /reports` (declared BEFORE /{report_id}) — list: {id, title, created_at, section_count}.
- `GET /reports/{report_id}` — persisted report; 400 INVALID_REPORT (uuid), 404 REPORT_NOT_FOUND, 503 PERSISTENCE_UNAVAILABLE.
- All auth-gated, tenant from JWT; Cube queries thread tenant_id (RLS-correct data per ADR 008).
